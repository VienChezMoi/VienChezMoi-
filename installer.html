Ouvrir dans Chrome pour installer

✓ L'appli est installée sur ton écran d'accueil.

Pour l'ajouter sur ton iPhone :

  1. Appuie sur ⋯ en haut à droite, puis Ouvrir dans le navigateur (ou Ouvrir dans Safari).
  2. Vérifie que la page est ouverte dans Safari.
  3. Appuie sur Partager en bas de l'écran (le carré avec une flèche vers le haut).
  4. Choisis Sur l'écran d'accueil, puis Ajouter.

Pour l'ajouter sur ton téléphone :

  1. Appuie sur les ⋮ en haut à droite de Chrome.
  2. Choisis Installer l'application ou Ajouter à l'écran d'accueil.
